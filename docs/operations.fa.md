# راه‌اندازی و وضعیت نسخه اجرایی

## اجرای محلی

نیازمندی: Node.js 24 یا جدیدتر، Chrome/Edge نصب‌شده برای PDF.

```bash
npm install
npm run dev
```

سپس `http://127.0.0.1:3000` را باز کنید و از صفحه «شروع ارزیابی» نام، ایمیل و سمت را وارد کنید. در این مسیر عمومی تأیید ایمیل، رمز عبور و پنل کاربری وجود ندارد؛ یک نشست موقت برای همان نوبت ساخته می‌شود. برای پاک‌سازی نصب آزمایشی، `.data` را پس از توقف برنامه حذف کنید.

مسیر قدیمی حساب و فرمان مدیر برای نگهداری داخلی API باقی مانده‌اند، اما در تجربه عمومی استفاده نمی‌شوند.

## متغیرهای تولید

یک `APP_URL` عمومی HTTPS، `APP_SECRET` تصادفی حداقل ۳۲ نویسه، `DATA_DIR` روی دیسک پایدار و SMTP لازم است. `MAIL_MODE=smtp` و `MAIL_FROM` و `SMTP_HOST` را تنظیم کنید؛ در صورت نیاز `SMTP_PORT` (پیش‌فرض ۵۸۷)، `SMTP_SECURE`، `SMTP_USER` و `SMTP_PASS`. سرور خارج از localhost بدون این تنظیمات عمداً متوقف می‌شود. نمونه در [.env.example](../.env.example) است؛ `.env` هرگز commit نشود.

این نسخه برای یک نمونه Node با دیسک پایدار و SQLite طراحی شده است. اجرای آن روی filesystem موقت یا چند instance مستقل بدون راهکار قفل/دیتابیس مشترک پشتیبانی نمی‌شود. TLS، پشتیبان‌گیری، مجوز فایل `.data` و مدیریت Chrome را در زیرساخت تنظیم کنید.

## داده و حریم خصوصی

نام، ایمیل، سمت، نشست موقت، پاسخ‌ها و گزارش ذخیره می‌شوند. رمز و تأیید ایمیل در مسیر عمومی دریافت نمی‌شود. پیش‌نویس‌ها و نتایج پس از ۱۸۰ روز بی‌فعالیتی در پاک‌سازی دوره‌ای حذف می‌شوند؛ حذف دقیق نوبت و داده زنده وابسته باید با اپراتور هماهنگ شود. حذف نسخه پشتیبان به رویه اپراتور و چرخه حداکثر ۳۰روزه پیشنهادی وابسته است و خودکار ادعا نمی‌شود.

پنل مدیریت، نام/ایمیل/وضعیت کاربران را جدا از projection نتایج نشان می‌دهد. نتایج مدیریت بدون شناسه مالک، نام، ایمیل، عنوان آزاد و زمان دقیق ساخته می‌شوند؛ این نمایش بدون هویت است و ناشناس‌سازی مطلق نیست، به‌خصوص در نمونه کوچک.

پیش از دریافت پاسخ واقعی، متن اطلاعیه [حریم خصوصی](../app/privacy/page.tsx) را با مالک محصول، مبنای حقوقی، مدت نگهداری و رویه پشتیبان نهایی کنید.

## بررسی

```bash
npm run validate
npm test
npm run typecheck
npm run build
npm audit --omit=dev --audit-level=high
```

PDF شش صفحه A4 واقعی و فارسی تولید می‌شود. در برخی نسخه‌های Chrome/Edge ویندوز، لایه استخراج متن PDF برای خط فارسی ممکن است نگاشت حروف زمینه‌ای ارائه دهد، هرچند شکل‌دهی دیداری درست است؛ تست PDF صفحه‌ها، ساختار، برچسب‌های ASCII و گیت‌ها را بررسی می‌کند و ادعای استخراج ساده فارسی نمی‌کند.

نسخه اول ویدئو، پرداخت، قیمت نهایی، اتصال مدل AI و ارسال ایمیل بدون SMTP را فعال نمی‌کند. دسترسی آزمایشی رایگان است و گزارش نتیجه «خودارزیابی اولیه» است، نه ممیزی یا تضمین صرفه‌جویی.
