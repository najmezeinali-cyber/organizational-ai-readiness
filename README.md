# بسته تعاملی آمادگی و شروع هوش مصنوعی

محصولی فارسی برای مدیران مهندسی، تدارکات و مدیریت پروژه در شرکت‌های مهندسی و EPC.

> وضعیت اولیه واحدتان را برای استفاده از هوش مصنوعی بررسی کنید، موانع شروع را بشناسید و از میان چند کاربرد متناسب، یک کار تکراری را برای آزمایش ۳۰روزه انتخاب کنید؛ همراه با قالب‌ها و راهنمای اجرا برای شروع با ابزار رایگان، با هدف کاهش زمان و بهبود کیفیت.

## وضعیت پروژه

پیش‌نویس محتوایی پرسش‌نامه و قواعد نتیجه آماده است: بانک شامل ۴۲ سؤال است و هر مدیر بر اساس حوزه خود دقیقاً ۳۰ سؤال می‌بیند (۲۴ مشترک + ۶ تخصصی). این پیش‌نویس هنوز با مدیران واقعی اعتبارسنجی نشده است. اپلیکیشن، احراز هویت، موتور اجرایی قواعد و قابلیت دریافت PDF هنوز پیاده‌سازی نشده‌اند.

این مخزن مستقل از هر پروژه دیگری ایجاد شده است و شامل هیچ فایلی از پروژه سالن زیبایی نیست.

## اولین خروجی توسعه

۱. نمونه داشبورد مدیریتی گرافیکی و راست‌به‌چپ.
۲. نمونه گزارش فارسی ۴ تا ۶ صفحه‌ای با قابلیت دریافت PDF.
۳. سناریوی نمایشی مدیر مهندسی شرکت EPC؛ داده‌ها و نتایج نمونه باید آشکارا فرضی باشند.

## بررسی ساختار محتوا

با Node.js نسخه ۲۰ یا جدیدتر، بدون نصب وابستگی:

```bash
node scripts/validate-content.mjs
```

این بررسی تعداد و ساختار سؤال‌ها، مسیرهای ۳۰سؤالی و پوشش نگاشت اقدامات را کنترل می‌کند؛ جای آزمون محتوایی با مدیران یا تست موتور اجرایی آینده را نمی‌گیرد.

## اصول

- نتیجه، «خودارزیابی اولیه» است؛ نه ممیزی رسمی یا تأیید قطعی آمادگی سازمان.
- ابزار نتیجه یا صرفه‌جویی مشخصی را تضمین نمی‌کند.
- پیشنهادها باید مستقل از خرید مشاوره قابل اجرا باشند.
- استفاده از داده محرمانه در ابزار عمومی بدون مجوز مجاز فرض نمی‌شود.
- نسخه اول با قواعد مشخص کار می‌کند و به مدل AI متصل نیست.
- دوره آفلاین مستقل جزو محدوده محصول نیست.
